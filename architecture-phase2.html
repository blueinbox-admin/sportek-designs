Sportek AI: Phase 2 Architecture

Phase 1 gave the team three reliable single-source bots, each answering about one system. Phase 2 builds on that foundation to do the thing a single source can't: answer blended questions that cross Shopify, QuickBooks, and HubSpot.

What makes combined answers trustworthy is the company context layer: a small store Sportek owns that holds its language and rules, what a style code means, which rep nickname is whom, and how a sale is counted. With that in place, one assistant can reason across all three sources in Sportek's own terms instead of guessing.

The part Sportek builds and owns

Company context layer

The connectors know the data. They don't know Sportek's language or rules: what a style code means, which rep nickname is whom, or that a "sale" is counted after returns and credits. That knowledge is different at every company, so no tool ships it for you. It lives here, in a small store Sportek owns and keeps current, and it is what turns three separate sources into one trustworthy combined answer.

The assistant reads from the store and uses it two ways, on every question ↓
Into the prompt
Short, always-true rules (for example, "a sale is the invoice after returns and credits") ride along on every question, so the assistant answers in Sportek's terms by default.
As a lookup it can pull
Big reference tables (style codes, rep aliases, customer matches) are fetched only when a question needs them, instead of carrying the whole list every time.
This store is separate from the source connectors: those carry the facts, this carries the meaning, and the assistant brings them together on each question. It's the small piece Sportek builds and owns, and the reason a combined answer can be trusted.
How the build runs
David starts by building a starter set of the team's most common questions, with answers the team approves, and that set is what the assistant is trained on and judged against. It goes live once it answers that set reliably, and an ongoing retainer keeps it accurate as the business changes, adds new questions, and updates how its data is organized.
